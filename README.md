## “便宜”便宜在哪，坑又埋在哪

先看市场上的实际成交价。人民币这一档：DogYun 香港-CLD 1核1G/15G/30Mbps/300G 是 **¥10/月**，香港特惠 1核1G/15G/30Mbps/500G 是 **¥15/月**；雨云东京 1核1G/20G/50M 限流量 **¥16.8/月**；快云香港 CN2 1核1G/20M/200G **¥29/月**。美元这一档：VPS.org 最低 **$2.50/月**，JustVPS Standard 三 年付叠加优惠码后月均约 **$2.48**，RAKsmart 香港 1核1G/25G **$5.00/月**，DMIT 香港 Lite TINY **$6.9/月**。

价格能压到这个水平，原因不神秘：入门配置（1核1G）本身成本低、机房选在带宽批发便宜的地区、超售一部分资源、用长周期付款锁定现金流。这四条里，前两条是正常的商业选择，后两条才是你要小心的地方。

最常见的三个坑：**线路绕路**导致国内访问延迟高、掉包多；**流量口径含糊**，宣传“不限流量”但带宽只给 5M；**首期价和续费价不同**，第一年很便宜，第二年按原价续。

## 五个判断标准，比“哪家最便宜”更重要

### 1. 先把价格口径统一

月付价、年付折合月价、多年付折合月价，这三者不能混着比。

### 2. 线路决定延迟，不是机房位置决定延迟

同样是美国西海岸，走 AS4837 电信直连和走普通国际线路，体验能差出一倍。已公开的实测口径可以参考：雨云洛杉矶二区（CMI+AS9929）国内三网平均 **158ms**，东京三网直连 **50~80ms**；JustVPS 香港机房国内延迟约 **50~100ms**，美西 **150~200ms**。

反过来，机房位置好但线路不优化，延迟照样难看。有一份针对 LisaHost 台湾 ISP 住宅原生 IP 套餐的第三方测评，全国三网 ping 平均 **281.6ms**，测评者直接写明“非大陆优化线路，建议作为落地机，用香港或日本机器中转”。

这句话很关键：**“原生 IP”“住宅 IP”和“国内低延迟”是两件不同的事**。前者解决的是平台风控、账号环境问题，后者解决的是你打开网页快不快。买之前先想清楚自己要哪个。

### 3. 带宽和流量是两个独立参数

带宽是管道粗细，流量是一个月能过多少水，别混为一谈。

- 雨云洛杉矶：10M~25M 带宽，**不限流量**
- JustVPS：300Mbps~1Gbps 带宽，**不限流量**
- VPS.org：500GB~15TB，**限量**
- Coffee Host：512GiB~32TiB，**限量**

“不限流量 + 10M 带宽”和“1Gbps 带宽 + 1TB 流量”是两种完全不同的产品。前者适合长期挂着跑小服务，后者适合短时间传大文件。看到“不限流量”四个字先去找带宽数字，看到“1Gbps”先去找月流量上限。

### 4. 低价套餐的隐性成本

几个真实存在的例子：

- VPS.org 的 $2.50 套餐**仅含 IPv6**，要 IPv4 得再加 **$2/月**，实际支出变成 $4.50；每日备份额外加收套餐价的 **30%**，每周备份加 **20%**。
- DMIT 的 Standard 系列月付**不保证 IP 对大陆可用**，想保证亚洲可用要加 $1，个人原因换 IP $5/次。
- 部分低价套餐标“可安装 Windows”，但 Windows 授权需要你自己解决。

把这些加回去再比价，很多“最便宜”就不成立了。

### 5. 退款期和试用，是低价试错的唯一保险

已知的退款政策差异很大：雨云 **7 天**无理由自助退款，JustVPS **15 天**无条件退款，VPS.org **30 天**，Kuaiyun **30 天**。

## 什么需求不该买便宜 VPS

这段是给你省钱的。

**要跑大带宽视频、做 CDN 节点**：别买。便宜 VPS 的带宽要么是 10M~50M 的小水管，要么标 1Gbps 但月流量只有 1T，跑视频分分钟超限。

**对 SLA 要求极高的商业关键系统**：别买。便宜 VPS 的定位就是非托管、尽力而为。雨云自己的说明里都写了“不适合对 SLA 要求极高的商业关键系统”，JustVPS 也明说自己是非托管 VPS、没有 CN2 GIA 这类高端优化线路。

**需要欧洲、南美、中东节点**：LisaHost 目前公开的主要是美国、香港，加上新上线的德国法兰克福。真要覆盖全球，JustVPS 的 43 个机房更合适。

**完全不想碰命令行**：便宜 VPS 基本都不含托管服务，装环境、配防火墙、做备份都得自己来。要托管就去看虚拟主机或带面板的套餐。

LisaHost 自身也有明确的边界：它的住宅 IP 系列**不是国内优化线路**，第三方测评的台湾 ISP 住宅 IP 套餐三网平均 281.6ms，测评者建议做落地机、配合香港或日本机器中转。如果你的唯一诉求是“国内打开快”，选它的 CN2 GIA 或香港三网直连系列，别选住宅 IP 系列。

## 购买流程与常见问题

**下单流程**：进官网 → 选产品线（美国 CN2 GIA / 美国住宅 VDS / CERA 高防 / 香港 iCable / 香港三网直连 / 香港 HGC）→ 选具体型号 → 选计费周期 → 结算。建议第一次先买 ￥2 试用或最短周期，确认延迟和系统模板再续长周期。

**能装宝塔、1Panel 吗？** 能。这类面板是免费软件，装在你的 VPS 上，不额外收费。需要的是最低 1G 内存 + 20G 硬盘，表里绝大多数套餐都满足。装之前确认系统模板是纯净版（Debian/Ubuntu/CentOS 一类），别选带预装环境的镜像。

**1Gbps 带宽是独享的吗？** 不是。VPS 的带宽标注通常是端口上限或共享峰值，实际能跑多少取决于邻居和上游。真要独享带宽，价格会高一个量级。

**便宜 VPS 会不会超售？** 会，区别只在超售比例。判断办法：买之前看有没有公开的 CPU 型号和 UnixBench 跑分，买之后自己跑一次磁盘 I/O 和网络测速，和宣传值差太多就在退款期内退掉。

**年付跑路了怎么办？** 没有好办法。降低风险的做法是：第一次只买最短周期，确认商家稳定运行几个月再考虑年付；年付金额控制在你能承受损失的范围内；优先选有明确退款政策的商家（7 天、15 天、30 天这几档都算有保障）。

**要不要额外买 IPv4？** LisaHost 表里的套餐都带独立公网 IP，不涉及这个问题。但如果对比的是 VPS.org 那类 $2.50 起的套餐，一定要把 IPv4 的 $2/月加回去再比价。

**能不能装 Windows？** LisaHost 的部分型号标注了“可安装 Windows”，具体以你选的套餐页面说明为准，Windows 授权需要自行解决。
